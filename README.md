
# AttendX-Test-Scripts

## Project Description
This repository contains sample automation test scripts
for a student attendance application called AttendX.

## Test Scripts

### 1. login_test.py
Checks that the sample username and password fields
contain values.

### 2. attendance_test.py
Checks that the student ID is provided and the attendance
status is either Present or Absent.

## Technologies
- Python
- Git
- GitHub

## How to Run

Run the login test:
python login_test.py

Run the attendance test:
python attendance_test.py
